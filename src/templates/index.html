🌍 ShakeMap

A seismic monitoring platform that stores SeisComP earthquake events, queues ShakeMap generation, and shows intensity, PGA, PGV and PSA products as images and on an interactive map.

What We Do

We keep a catalog of earthquake events with origin time, location (GE/EN), depth and ML magnitude, generate ShakeMap products for them, and publish selected events to the IES website.

How It Works

Events arrive from SeisComP through the API or are added manually. ShakeMap runs in a background queue, one job at a time, and results appear on each event's detail page.

Why It Helps

Event list, ShakeMap status, products and publishing live in one place, and role-based permissions control who can edit events, run ShakeMap or manage users.

Platform Flow
1) Ingest
Receive events from SeisComP via API key, or add them in the events page.
2) Validate
Apply auth, permissions, and input checks before persistence.
3) Process
Queue ShakeMap jobs and track status: waiting, running, generated or failed.
4) Deliver
View ShakeMap images and map layers on the event page, and publish the event to the IES website.
