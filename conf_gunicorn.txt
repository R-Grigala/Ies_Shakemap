Gunicorn systemd სერვისის შექმნა (IES Monitoring)
==================================================

1) შექმენი სერვისის ფაილი
-------------------------
sudo nano /etc/systemd/system/ies_shakemap_main.service

Template repository-შია: ies_monitoring_main.service

ყურადღება: template-ში ამჟამად ორი `ExecStart=` წერია (Celery + Gunicorn) `Type=simple`-ით.
systemd ასეთ unit-ს არ ტვირთავს ("more than one ExecStart= setting"). Main unit-ში დატოვე
მხოლოდ Gunicorn; Celery ცალკე unit-ით ეშვება (conf_celery.txt, ies_monitoring_celery.service).

რეკომენდებული კონფიგი:

[Unit]
Description=IES Shakemap Main Flask App (Gunicorn)
After=network.target

[Service]
Type=simple
User=sysop
Group=www-data
WorkingDirectory=/var/www/Ies_Shakemap-main

Environment="PATH=/var/www/Ies_Shakemap-main/venv/bin:/home/sysop/miniconda3/bin:/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/bin"
Environment="CONDA_EXE=/home/sysop/miniconda3/bin/conda"
Environment="SHAKEMAP_CONDA_ENV=shakemap"
Environment="APP_ENV=production"
EnvironmentFile=/var/www/Ies_Shakemap-main/.env

# app.py exposes flask_app = create_app()
ExecStart=/var/www/Ies_Shakemap-main/venv/bin/gunicorn -w 4 -b 127.0.0.1:5000 app:flask_app

Restart=always
RestartSec=5
TimeoutStartSec=60
TimeoutStopSec=30

[Install]
WantedBy=multi-user.target


2) ჩაიტვირთოს systemd-ს ახალი კონფიგი
-------------------------------------
sudo systemctl daemon-reload


3) ჩართე სერვისი boot-ზე
------------------------
sudo systemctl enable ies_shakemap_main


4) გაუშვი/გადატვირთე სერვისი
----------------------------
sudo systemctl restart ies_shakemap_main


5) შეამოწმე სტატუსი
------------------
sudo systemctl status ies_shakemap_main


6) ცოცხალი ლოგები
-----------------
journalctl -u ies_shakemap_main -f


სასარგებლო შენიშვნები
----------------------
- app target არის app:flask_app, რადგან app.py-ში გაქვს:
  flask_app = create_app()
- `.env` იკითხება WorkingDirectory-დან (load_dotenv('.env')), ამიტომ WorkingDirectory და
  EnvironmentFile ერთსა და იმავე საქაღალდეზე უნდა მიუთითებდეს.
- თუ შეცვლი სერვისის ფაილს, ყოველთვის თავიდან გაუშვი:
  sudo systemctl daemon-reload
  sudo systemctl restart ies_shakemap_main
- ShakeMap ბრძანებები Celery worker-ში ეშვება, არა Gunicorn-ში. თუ ვერ ეშვება, გადაამოწმე:
  which conda
  bash -lc 'eval "$(/home/sysop/miniconda3/bin/conda shell.bash hook)" && conda activate shakemap && command -v sm_create && command -v shake'
